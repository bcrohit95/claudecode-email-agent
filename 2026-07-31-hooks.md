# Claude Code Skill of the Day: Hooks

**Date:** 2026-07-31

## What Are Hooks?

Hooks are shell commands that Claude Code runs automatically at specific lifecycle events — like before a tool runs, after a tool completes, or when a session starts. They let you wire in your own logic (linting, logging, notifications, safety checks) without modifying Claude's behavior manually each time.

## How They Work

You configure hooks in your `.claude/settings.json` (project-level) or `~/.claude/settings.json` (global). Each hook specifies a trigger event and the command to run. Claude Code executes that shell command at the right moment, and if the command exits non-zero, Claude can be blocked or warned.

## Copy-Pasteable Example

Add this to `.claude/settings.json` to auto-run your linter after every file edit:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "npm run lint --silent 2>&1 | head -20"
          }
        ]
      }
    ]
  }
}
```

This triggers after any `Edit` or `Write` tool call, runs your linter, and surfaces the first 20 lines of output to Claude — so it can see and fix lint errors immediately.

## Available Hook Events

- `PreToolUse` — runs before a tool executes (can block it)
- `PostToolUse` — runs after a tool completes
- `SessionStart` — runs once when the session begins
- `Stop` — runs when Claude finishes responding

## Try It Yourself

1. Open (or create) `.claude/settings.json` in your project root.
2. Add a `PostToolUse` hook that echoes a timestamp after every Bash command:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "echo '[hook] Bash ran at' $(date +%H:%M:%S)"
          }
        ]
      }
    ]
  }
}
```

3. Start a Claude Code session and run any Bash command — you'll see the hook output appear.

Hooks are one of the most powerful ways to make Claude Code fit your team's workflow. Explore the full hook docs with `/help hooks` inside Claude Code.
