# Tool Use

Tool Use lets you give Claude custom functions it can call during a conversation — things like searching a database, fetching a URL, or running a shell command. You define each tool with a name, description, and JSON Schema for its parameters; Claude reads those definitions and decides on its own when to invoke them. Your code executes the actual function and returns the result, then Claude continues the conversation with that information in hand.

## Copy-pasteable example

```python
import anthropic

client = anthropic.Anthropic()

tools = [
    {
        "name": "get_weather",
        "description": "Get the current weather for a city.",
        "input_schema": {
            "type": "object",
            "properties": {
                "city": {"type": "string", "description": "City name, e.g. 'London'"}
            },
            "required": ["city"]
        }
    }
]

# First call — Claude may decide to use the tool
response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    tools=tools,
    messages=[{"role": "user", "content": "What's the weather in Tokyo?"}]
)

# Handle tool use
if response.stop_reason == "tool_use":
    tool_block = next(b for b in response.content if b.type == "tool_use")
    city = tool_block.input["city"]

    # Your real logic here — this is a stub
    weather_result = f"Sunny, 28°C in {city}"

    # Second call — send result back to Claude
    final = client.messages.create(
        model="claude-sonnet-5",
        max_tokens=1024,
        tools=tools,
        messages=[
            {"role": "user", "content": "What's the weather in Tokyo?"},
            {"role": "assistant", "content": response.content},
            {
                "role": "user",
                "content": [
                    {
                        "type": "tool_result",
                        "tool_use_id": tool_block.id,
                        "content": weather_result
                    }
                ]
            }
        ]
    )
    print(final.content[0].text)
```

## Try it yourself

Add a second tool — say `get_time(city: str)` — to the `tools` list above, then ask Claude "What time and weather is it in Paris?" Watch how Claude calls both tools in sequence (or in parallel if you enable `tool_choice: "auto"`). Experiment with making one tool's description vague and notice how that affects whether Claude chooses to use it.
